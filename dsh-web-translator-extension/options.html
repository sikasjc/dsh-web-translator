dsh翻译 · 扩展设置

调用本机 DSH 插件 API 做网页翻译；模型与提示词在 DSH 设置页中编辑。

连接

默认 http://127.0.0.1:3080（DSH Web / 插件 API 所在地址）。manifest 的 host_permissions 仅覆盖 127.0.0.1:3080 与 localhost:3080，改端口需同步改 manifest 并重新加载扩展。

翻译

按屏触发：滚动停稳后整屏翻译（请求更少、译文更整齐）；按块懒加载：只翻进入视口的段落（最省 token）。预加载决定当前视口下方额外翻译多少，选项在新一次翻译时生效。

快捷键在浏览器扩展快捷键页自定义（建议 Command+K / Ctrl+K）：chrome://extensions/shortcuts

使用与隐私

  • 在任意网页点击工具栏图标、按 Alt+T，或点击页面右下角悬浮球打开面板，点「翻译此页」。
  • 选中文本或双击单词会弹出查词卡，可发音、加入单词本（单词本在 DSH 设置页复习）。
  • 所有网络请求都由扩展后台发往本机 DSH；页面文本经 DSH 发送给你在 DSH 中配置的模型服务，扩展本身不保存页面内容。
  • 需要先安装并启用 DSH 插件「dsh翻译」，DSH Web 默认运行在 127.0.0.1:3080。
